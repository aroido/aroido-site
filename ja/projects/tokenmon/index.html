Tokenmon

コーディングを続けるだけ。Tokenmonが静かに集めます。

Claude Code および Codex の使用は、Mac メニュー バーでの受動的な検出、自動結果、およびローカル Dex の進行状況になります。

ゲームプレイにアカウント、ローカルファースト、プロンプト テキストは必要ありません。

なぜ人々はそれをオープンにしておくのか

邪魔にならない遊び心のある相棒

Tokenmon は、すでに発生している作業をバックグラウンドでの小さな報酬ループに変える場合に最も強力です。

受け身

手動の戦闘フローはありません

このアプリは、コーディングをやめて出会いをタップするように要求しません。それらは自動的に解決されます。

アンビエント

メニューバーは一目瞭然です

作業をダッシュ​​ボード セッションに変えることなく、現在の状態、進行状況、最近の出会い、または Dex ビューが必要なときに開きます。

地元

コレクション状態は Mac 上に存在します

現在のパブリック ビルドにはアカウントやクラウド同期は必要ありません。製品のストーリーは、ローカルな状態と低摩擦の インストール経路 から始まります。

コアループ

コレクションループの感じ方

この製品は、AIコーディング アクティビティを探索に変え、アプリに遭遇結果を処理させます。

ステップ01

通常どおり Claude Code または Codex を使用します

Tokenmon は、個別の再生セッションではなく、既存のコーディング フローを中心に設計されています。

ステップ02

探索の進行状況のビルド

通常の使用法では、ゲームプレイのプロンプトや応答テキストを必要とせずに、次の遭遇に向けて進みます。

ステップ03

クリーチャーが現れて解決される

各遭遇は捕らえられるか逃げると自動的に終了し、インタラクションは軽量に保たれます。

ステップ04

Dex はローカルで満たされます

表示およびキャプチャされた進行状況は Mac に蓄積されるため、時間の経過とともにコレクションが増加する可能性があります。

信頼の境界線

遊び心は侵略を意味するものではありません

現在公開されているストーリーは意図的に狭く、ローカルファースト コレクション、アカウント要件なし、ゲームプレイに必要なプロンプト テキストなしです。

プロンプト

ゲームプレイではプロンプトテキストを保存する必要はありません

Tokenmon は、入力した内容を読み取ったりランク付けしたりするツールではなく、アンビエント コンパニオンとして判断されるべきです。

アカウント

今日はアカウントは必要ありません

アプリの試用は、ホストされたダッシュボードやサインアップ フローではなく、Mac インストール経路 から始まります。

ソース

ソースが利用可能なパブリックミラー

パブリック リポジトリには、出荷されたスナップショット、リリース アセット、およびインストール チャネルが含まれますが、日常のメンテナのワークフローは分離されたままになります。

視覚的証拠

実際の製品の表面は小さく、視認可能で、検査可能です

メニュー バー ループから始めて、コレクションとセットアップを表示する Dex ビューと設定ビューを調べます。

  • アニメーションメニューバーストリップ
  • 目撃され捕獲されたデックス
  • 設定とプロバイダーのセットアップ

インストール

パブリック Tokenmon ビルドをインストールする

GitHub Releases および Homebrew が現在のパブリック パスです。 Tokenmon には macOS Sequoia 以降が必要です。

オプション A. DMG をダウンロードする

DMG、リリース ノート、チェックサム、および Sparkle 更新メタデータの最新の GitHub リリースを開きます。

https://github.com/aroido/tokenmon/releases/latest
GitHub Releases から DMG をダウンロード GitHub を表示

パブリック リポジトリはソースから利用でき、出荷されたスナップショットのリリース ミラーとして機能します。

オプション B. Homebrew を使用してインストールする

ターミナルからインストールおよびアップグレードする場合は、cask パスを使用します。

インストールコマンド

brew install --cask aroido/tokenmon/tokenmon

リリース ビルドはアプリ内で更新できるため、Homebrew パスは主に初期インストールとターミナル駆動のアップグレード用です。

まず、通常の AIコーディング セッション中に開いたままにしておきます。

Tokenmon は、ループが仕事の傍らで生活できるほど静かに感じられる場合に意味があります。セッションを 1 回試してから、コレクションを保持する価値があるかどうかを判断してください。
