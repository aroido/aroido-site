LayoutRecall

macOSが乱すモニターレイアウトを復元。

LayoutRecall は、MacBook + ドック + マルチディスプレイ デスク用のオープンソース macOS メニュー バー アプリです。正常であることがわかっているレイアウトを一度保存​​し、スリープ、スリープ解除、または再接続後に元に戻します。

自動復元は保守的なままです。信頼性の低いケースは、意図的に手動のままになります。

リリースを開いてインストールする 視覚的な証拠を見る GitHub リポジトリを開きます
macOS メニュー バー アプリ GitHub リリース + Homebrew 信頼性を意識した復元

評判の良いデスク

信頼できるデスクを 1 つ保存し、安全に持ち帰ってください

LayoutRecall は、macOS が間違った順序や位置でマルチディスプレイ デスクを返した後に、使い慣れたマルチディスプレイ デスクを取り戻すという狭い問題向けに構築されています。

  • 現在のデスクから正常なレイアウト プロファイルを保存する
  • ライブディスプレイの一致が強い場合にのみ自動的に復元します
  • アプリが推測を拒否した場合でも手動回復コントロールを表示しておきます

オープンソース ビルドからの現在の公開製品画面。

マコスが間違ったとき

LayoutRecall が修正するもの

このアプリは意図的に範囲を狭めています。完全なディスプレイ管理スイートを装うのではなく、すでに信頼しているデスクを復元します。

睡眠/覚醒

同じモニターが間違った順序で返される

接続されたディスプレイ セットが以前に保存したものと強く一致する場合、保存されたプロファイルを復元します。

再接続

ドックの再接続によりメインディスプレイまたは原点が変更されます

再接続するたびにデスクを手動で再構築するのではなく、既知の配置に戻します。

信頼性が低い

自動復元は危険です

マッチングが十分に強力でない場合、アプリはすぐに停止し、診断を表示し、手動で回復し続けます。

今すぐ

直接的な回復制御が必要な場合

制御が必要な場合は、メニュー バーから [今すぐ復元]、[レイアウトの適用]、[番号の表示]、および関連するコントロールを使用します。

フィット

この製品の対象者

LayoutRecall は、元に戻したい正確なモニター レイアウトをすでに知っている人にとっては最も強力です。

デスクのセットアップ

MacBook + ドック + 2 台以上の外部ディスプレイ

これは、配置が安定しているにもかかわらず、macOS がディスプレイを間違った場所に戻し続けるリピートデスク向けに構築されています。

信頼

盲目的な推測をせずに回復したい人

自動復元は、信頼性の高い一致に対してのみ実行されます。自信が弱い場合、アプリは透明性を保ち、最終的な動きはユーザーに委ねられます。

境界

巨大なディスプレイ管理スイートではない

4 つ以上のディスプレイを備えたすべてのエッジ ケースに魔法の答えが必要な場合、この製品は意図的にその約束よりも狭いものになっています。

視覚的証拠

曖昧な有用性の主張ではなく、実際の UI の証拠

現在のパブリック ビルドでは、診断、プロファイル、リカバリ コントロールを推測に隠すのではなく、製品内に直接表示します。

  • 信頼性を意識した復元
  • 診断を常に表示できるようにする
  • Proファイルと手動フォールバック

インストール

署名付きアプリを試すか、Homebrew を使用してインストールします

GitHub Releases および Homebrew カスクは、最速のパブリック パスです。この製品は、実際の復元コマンドの displayplacer への依存関係について正直に保ちます。

オプション A. GitHub Releases

署名された DMG をダウンロードし、LayoutRecall をアプリケーションにドラッグし、メニュー バーからベースライン レイアウトを保存します。

https://github.com/aroido/layoutrecall/releases
最新の GitHub リリースを開く GitHub リポジトリを開く

displayplacer が見つからない場合、LayoutRecall はその依存関係の状態を明らかにし、復元コマンドを実行する前にインストール フローをガイドできます。

オプション B. Homebrew

Homebrew パスを使用する場合は、パブリック カスクからインストールします。

インストールコマンド

brew install --cask aroido/layoutrecall/layoutrecall

保存されたレイアウトの復元は、PATH で使用できる displayplacer に依存します。

取り戻したいデスクを 1 つから始めます。

LayoutRecall は、既知の正常なデスク レイアウトがすでにあり、macOS のドリフト後にそれを復元するためのより安全な方法が必要な場合に最も説得力があります。
