公開プロダクト

現在公開されているもの

パブリック レーンには、明確なフィット ストーリーを備えた製品、動作する インストール経路、およびツールの目的を説明する製品ページが掲載されています。

VibeSmith

Cursor および Claude Code を使用するマルチリポジトリ チーム用の AIコーディング リポジトリドリフト 監査レイヤー。

ステータス: GitHub のオープンソース (ライブ デモ、リリース ノート、および インストール経路 を含む)

  • 対象: 3 つ以上のアクティブな AIコーディング リポジトリを実行しているマルチリポジトリ チーム
  • サーフェス: ドリフト、隠れた結合、コンテキスト重視のセットアップ
  • 最初に: 1 つのライブ リポジトリ、1 つのベースライン、1 つのクリーン キックオフ
製品ページを開く リリースおよびインストール ガイドを開く GitHub リポジトリを開く

LayoutRecall

スリープ、ウェイク、またはドックの再接続後にスクランブルされたモニター レイアウトを復元する macOS メニュー バー ユーティリティ。

ステータス: GitHub、署名付きアプリのダウンロード、および Homebrew インストール経路 のオープンソース

  • 対象: MacBook + ドック + 2 台以上のディスプレイ デスクが常に漂っている場合
  • 復元: macOS が間違った状態に戻す場合に保存されたモニター レイアウト
  • まずは正常なデスクを 1 つ保存し、一致が安全な場合にのみ復元します。
製品ページを開く リリースおよびインストール ガイドを開く GitHub リポジトリを開く

Tokenmon

Claude Code および Codex の使用を受動的遭遇とローカル Dex の進行に変える macOS メニュー バー アプリ。

ステータス: DMG リリース、Sparkle アップデート、および Homebrew インストール経路 を含む GitHub でソースが利用可能

  • 対象: 日中 AIコーディング ツールを開いたままにする macOS 開発者
  • 変化: 通常の使用量を探索の進行状況、自動結果、Dex の成長に変える
  • 信頼ライン: ローカルファースト コレクション状態、アカウントなし、ゲームプレイに必要なプロンプト テキストなし
製品ページを開く DMGをダウンロード GitHub を表示

Labs

今のところ実験的なもの

すべての有望なビルドが完成品であるかのように振る舞う必要はありません。 Labs では、適切な公開形式が明らかになるまで、ゲーム、プロトタイプ、および一部のユーティリティが動き続けます。

ゲーム

遊べるアイデアと感触ファーストの実験

小規模なゲームやインタラクションの実験は、製品言語をあまり早く借用しなくても、Labs で迅速に進めることができます。

  • 焦点: 仕組み、リズム、視覚的な感触、ループを維持する価値があるかどうか
  • 公開タイミング: 再生ループが繰り返された後のみ
ブログでスタジオノートをフォローしてください

実験

将来製品になる可能性のある新しいツール

一部のビルドは狭い範囲に留まり、内部ユーティリティになるか、適合性が明らかになって初めて公開ソフトウェアに移行します。

  • 焦点: 広範なプラットフォームの約束ではなく、特定のワークフローの摩擦
  • 意思決定ゲート: プロモーションの前に製品ページ、プルーフ、および インストール経路 を準備する必要があります
