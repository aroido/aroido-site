VibeSmith

AI Agent Components Manager for Cursor and Claude Code.

VibeSmith unifies Skills, Agents, Commands, Hooks, and Rules in one local-first workspace so power users can scale without configuration chaos.

Problem

Power users often run 10+ components across 3-5 projects, and manual tracking causes context drift and hidden dependency issues.

Approach

Unified management, dependency graph visualization, smart search, and auto-sync workflows reduce operational complexity.

Experience

Dashboard and graph views keep active components and release impact visible before issues hit production.

Outcome

Faster first scan, lower configuration drift, and cleaner issue-to-merge execution.

STACK

Current focus stack

  • Unified management for Skills, Agents, Commands, Hooks, and Rules
  • Dependency graph + smart search for hidden coupling and quick navigation
  • Local-first operation today, Team Beta and Cloud expansion in Phase 2
