# Prompt

## Mission

- 사용자 가치와 비즈니스 목표를 동시에 개선한다.
- 각 사이클은 작고 검증 가능한 변경으로 끝낸다.

## Boundaries

- 보호 브랜치 직접 푸시 금지
- 시크릿 하드코딩 금지
- 검증 실패 상태에서 완료 선언 금지

## Success Criteria

- `./scripts/ai-verify --mode full` 통과
- 변경 의도/근거/롤백 정보가 `Implement.md`에 기록됨
- 다음 사이클 시작 조건이 `Documentation.md`에 기록됨

## Current Objective

- 현재 목표를 한 문장으로 유지하고, 목표가 바뀌면 즉시 갱신한다.
