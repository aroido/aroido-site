# perf-a11y

## Baseline

- Accessibility: WCAG 2.2 AA
- Performance: Core Web Vitals (`LCP`, `INP`, `CLS`)

## Checks

1. 시맨틱 HTML/랜드마크 사용
2. 키보드 접근 가능성
3. 색 대비/포커스 표시
4. 이미지 크기 고정 및 레이아웃 시프트 최소화
5. 번들/리소스 과다 로드 여부
