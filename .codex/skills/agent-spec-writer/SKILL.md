# agent-spec-writer

## Responsibilities

1. 요구사항을 Scope/Non-goals로 분리
2. 요구사항을 `MUST/SHOULD/MAY` 형식으로 정규화
3. Acceptance Criteria를 정량 기준으로 작성
4. Evidence 링크(표준/공식 문서) 첨부

## Output Contract

- 파일 경로: `docs/specs/*.md`
- 필수 섹션: Scope, Non-goals, Requirements, Acceptance Criteria, Evidence
