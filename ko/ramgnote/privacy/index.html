람지노트

개인정보 처리방침

메모는 개인 기록입니다. 람지노트가 iPhone에서 처리하는 정보, Apple 서비스로 정보가 전달되는 경우와 사용자가 선택할 수 있는 사항을 안내합니다.

시행일: 2026년 10월 1일

운영자·개인정보 문의 담당자: 송희섭

람지노트 문의 메일 작성 지원 페이지 열기

기기에 저장하는 기록

메모 본문·분류, 입력한 장소 이름·주소, 저장한 좌표, 작성·수정 시각, 선택한 사진의 사본, 저장·동기화 식별 정보를 앱 전용 공간에 보관합니다. 초안과 입력 복구 자료는 작성 중인 내용을 보존하는 데 사용합니다. 앱 설정과 iCloud 계정 매핑 정보로 설정 및 기록 공간을 구분합니다. 별도 람지노트 회원가입은 없습니다. iCloud 연결이 구성된 경우 기록 동기화를 켜기 전에도 계정 사용 가능 여부를 확인할 수 있습니다.

선택한 사진

시스템 사진 선택기를 통해 사용자가 고른 사진을 가져옵니다. 방향을 적용하고 크기를 조정한 JPEG 사본을 앱에 저장하며, 원본 EXIF·GPS·IPTC 메타데이터를 사본에 복사하지 않습니다. 첨부를 지워도 Apple 사진 앱의 원본은 삭제하지 않습니다. 메모당 사진을 최대 6장 첨부할 수 있습니다. 현재 버전은 영상 첨부와 앱 내 카메라 촬영을 제공하지 않습니다.

위치와 근처 메모 알림

허용한 위치의 좌표·정확도·측정시각을 메모 위치 연결과 기기 내 저장 시설 비교에 사용합니다. 자동 메모 알림은 선택 기능이며 위치 접근 ‘항상’, ‘정확한 위치’ 및 알림 허용이 필요합니다. 켜면 앱을 전면에서 사용하지 않을 때도 위치를 사용할 수 있습니다. 반복 알림을 줄이기 위해 장소별 근접·멀어짐·알림 시각과 알림 설정을 기기에 보관합니다. 알림 묶음은 24시간 만료 기준이며 앱이 실행할 수 있는 때 정리합니다. 실내 매장이나 층을 감지하는 기능은 아닙니다. 앱에서 자동 알림을 끄거나 iPhone 설정에서 권한을 변경할 수 있고, 권한을 거부해도 수동 작성은 가능합니다.

Apple 지도와 장소 검색

MapKit으로 지도를 표시합니다. 장소 검색 시 입력한 검색어와 검색 영역을 Apple에 전달합니다. Apple 장소를 참조로 연결하면 장소 ID와 직접 쓴 별칭을 저장하고, 열 때 Apple에 최신 정보를 요청합니다. 이 참조는 메모 동기화에 포함될 수 있습니다. Apple 참조로 연결한 장소는 현재 도착 알림을 지원하지 않습니다. 지도에서 직접 선택한 장소는 좌표와 함께 별도로 저장합니다. 현재 구성에는 Naver 검색이 연결되어 있지 않습니다.

선택적 iCloud 기록 동기화

설정되어 사용할 수 있는 경우에도 전송 범위를 확인하고 동의한 뒤 동기화를 시작합니다. 현재 iCloud 기록 공간의 기존 메모, 장소 정보·좌표, 휴지통 기록, 삭제 이력과 동기화 메타데이터를 사용자 CloudKit 비공개 데이터베이스로 보냅니다. 초안·입력 복구 자료, 기기 전용 기록과 다른 계정 기록을 자동으로 옮기지 않습니다. 계정 식별 정보는 기록 공간 구분에 사용합니다. 동의는 이번 앱 실행과 해당 계정에 적용됩니다. 동기화를 끄거나 계정을 바꾸면 멈추지만 이미 전송한 자료는 삭제되지 않습니다. iCloud 용량과 연결 상태에 영향을 받으며, 기기 저장이나 연결됨 표시는 원격 백업 완료 확인이 아닙니다.

사진 동기화는 별도 조건이 있어요

사진 첨부는 기기에서 사용할 수 있습니다. 현재 일반 앱 구성에서는 사진의 클라우드 동기화를 켤 수 없습니다. 별도 동의 화면은 지원되는 구성에서 현재 iCloud 공간의 저장된 메모와 휴지통에 첨부한 기존 사진도 전송 대상이며, 초안과 다른 기록 공간은 제외한다고 안내합니다. 지원 버전에서 켠 경우 iCloud 용량과 네트워크 데이터를 사용합니다. 끄면 기록 동기화 세션도 멈추며 이미 업로드한 사진을 지우지는 않습니다. 모든 사진이 전송됐다고 가정하지 말고 개별 메모의 상태를 확인해 주세요.

Siri와 잠금화면 표시

Siri·앱 단축어는 요청한 메모 본문을 앱에 전달합니다. 앱이 전면으로 열리고 기기 잠금 해제가 필요하며, 앱이 별도 음성 녹음을 저장하지 않습니다. Siri 처리는 Apple 설정과 정책을 따릅니다. 근처 알림에는 본문 대신 개수가 표시됩니다. Live Activity는 사용자가 직접 시작하고 세션별로 메모 일부의 표시 여부를 선택합니다. 본문을 숨겨도 장소 이름은 표시될 수 있습니다. 주변 사람이 잠금화면에서 이 정보를 볼 수 있습니다. 활동을 종료해도 메모는 삭제되지 않습니다. 자동 Island·APNs relay는 운영 중인 서비스가 아닙니다.

보관과 삭제

저장한 메모는 사용자가 삭제할 때까지 보관합니다. 휴지통 기록은 30일 안에 복원하거나 그 전에 영구삭제할 수 있습니다. 명시적으로 저장한 초안은 생성 후 30일이 지나면 만료되며, 만료 자료와 더 이상 참조되지 않는 사진 사본은 앱이 저장소를 처리할 수 있을 때 정리합니다. 입력 복구 자료는 저장·버리기 또는 관련 기록 삭제 전까지 남을 수 있습니다. 삭제된 내용의 재생성을 막는 삭제 표시와 동기화 메타데이터가 남을 수 있습니다. 원격 삭제 변경은 동기화가 정상 실행돼야 전달됩니다. 계정을 바꾸면 과거 로컬 공간은 보존됩니다. 앱 삭제나 동기화 끄기는 iCloud 사본·시스템 백업의 삭제가 아닙니다. Apple 서비스는 기기 설정에서 관리하며, 지원팀이 Apple 관리 백업 전체의 즉시 삭제를 보장하지 않습니다.

보호 조치와 외부 서비스

기록 공간 분리와 iOS 파일 보호를 사용합니다. 이는 종단간 암호화나 별도 앱 비밀번호를 보장한다는 뜻은 아닙니다. iCloud·지도·Siri는 Apple이 운영하며 Apple 정책도 적용됩니다. 현재 앱 구성에는 광고·추적·외부 분석 SDK가 연결되어 있지 않고, 별도 앱 계정 서버나 자동 Island relay도 운영하지 않습니다. 향후 광고나 새로운 전송이 활성화되기 전 정책을 갱신하고 필요한 선택 절차를 제공합니다. 이 웹사이트는 Vercel에서 제공하며 Google Fonts에서 글꼴을 불러옵니다. 일반 웹 요청으로 IP 주소와 브라우저 정보가 해당 제공자에게 전달될 수 있습니다.

문의·권리 행사·변경 안내

열람·정정·삭제·처리 중단 문의는 송희섭, admin@aroido.com으로 요청할 수 있습니다. Apple ID 비밀번호를 요구하지 않고 기기·iCloud 기록의 처리 방법을 안내합니다. 기기 전용 기록 전체를 열람하거나 동기화되지 않은 자료의 복원을 보장할 수는 없습니다. 이메일로 문의하면 발신 주소·문의 내용과 사용자가 선택해 보낸 첨부를 답변과 문제 해결에 사용합니다. 중요한 처리 변경은 이 페이지와 시행일 갱신으로 안내합니다.

문의 처리가 끝나면 불필요한 자료는 지체 없이 삭제합니다. 법령상 보관이 필요한 경우는 제외합니다.
