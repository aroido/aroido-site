문의할 때 알려 주세요

앱 버전·iOS 버전·문제가 생긴 화면·기대했던 결과와 실제 결과를 알려 주세요. 화면 캡처의 개인 메모·사진·정확한 위치는 가려 주세요. Apple ID 비밀번호·인증번호·비밀 키는 보내지 마세요. 문의: admin@aroido.com, 운영자: 송희섭.

기록은 어디에 저장되나요?

메모와 첨부 사진 사본은 이 iPhone에 저장됩니다. 설정의 ‘기록 저장’에서 현재 공간과 동기화 상태를 확인하세요. 별도 앱 회원가입은 없습니다. iCloud 계정을 바꾸면 공간이 분리되며 이전 기록을 자동으로 옮기거나 지우지 않습니다. 저장 실패 시 작성 화면을 유지하고 재시도 또는 입력 복사를 이용해 주세요.

저장되면 백업도 완료되나요?

아닙니다. 선택적 iCloud 기록 동기화는 지원 설정·확인된 계정·이번 실행의 동의가 필요합니다. ‘연결됨’은 모든 기록의 전송 완료 확인이 아닙니다. 연결과 iCloud 용량을 확인한 뒤 설정에서 재시도하세요. 사진 클라우드 동기화는 별도 동의가 있으며 현재 일반 앱 구성에서는 사용할 수 없지만, 기기 내 사진 첨부는 가능합니다. 클라우드 백업이 완료됐다고 가정해 원본을 지우거나 앱을 재설치하지 마세요.

사진 첨부와 삭제

작성 화면의 사진 버튼에서 시스템 선택기를 열어 사진을 고르세요. 메모당 최대 6장을 지원합니다. 원본 EXIF·GPS·IPTC를 복사하지 않은 크기 조정 JPEG 사본을 만듭니다. 가져오기에 실패해도 기존 본문은 유지되니 다른 사진으로 시도해 주세요. 첨부 삭제는 Apple 사진 앱 원본의 삭제가 아닙니다. 이 버전은 영상과 카메라 촬영을 제공하지 않습니다.

근처 알림과 위치 권한

설정의 ‘자동 메모 알림’에서 항상 위치·정확한 위치·알림 상태를 확인하세요. 켜기 선택만으로 전달을 보장하지 않습니다. 위치 정확도·배터리·iOS 실행 제한에 따라 늦거나 오지 않을 수 있고, 강제 종료나 권한 해제도 영향을 줍니다. Apple 장소 ID 연결은 도착 알림을 지원하지 않으며 직접 저장한 시설은 기기에서 비교합니다. 실내 층은 감지하지 않습니다. 권한을 거부해도 수동 작성은 계속할 수 있습니다.

Siri와 잠금화면 메모

앱에 표시된 Siri 사용 문구를 따라 주세요. 기기 잠금을 해제하고 람지노트가 열리면 결과를 확인하세요. 위치를 얻지 못하면 나중에 장소를 연결할 메모로 남을 수 있으며, 저장 실패는 백업 성공이 아닙니다. Live Activity는 장소 상세에서 시작하고 세션별 표시 여부를 선택합니다. 본문을 숨겨도 장소 이름은 숨겨지지 않습니다. 도착 알림이 Island를 자동 시작하지 않습니다. 메모를 지우지 않고 표시를 종료할 수 있습니다.

복원과 삭제

설정의 ‘휴지통’에서 30일 안에 복원하거나 영구삭제할 수 있습니다. 저장된 메모·초안·입력 복구 자료·휴지통이 참조하는 동안 사진 사본은 남습니다. 원격 삭제는 정상 동기화를 기다리며, 동기화 끄기만으로 원격 자료를 지우지 않습니다. 앱 삭제로 로컬 자료를 잃을 수 있고 Apple 관리 백업·iCloud 자료는 별개입니다. 전송 여부가 불확실하면 앱을 삭제하기 전에 문의해 주세요.
