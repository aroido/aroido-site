공개 제품

지금 공개된 것

공개 레인에는 적합성 서사, 동작하는 설치 경로, 그리고 도구가 무엇을 위한 것인지 설명하는 제품 페이지가 함께 있어야 합니다.

VibeSmith

Cursor와 Claude Code를 쓰는 멀티 레포 팀을 위한 AI 코딩 레포 드리프트 audit 레이어입니다.

상태: GitHub 오픈소스, 라이브 데모, 릴리즈 노트, 설치 경로 제공 중

  • 대상: 활성 AI 코딩 레포 3개 이상을 운영하는 멀티 레포 팀
  • 드러내는 것: 드리프트, 숨은 결합, 컨텍스트가 무거운 세팅
  • 시작점: 실사용 레포 하나, 기준선 하나, 더 깔끔한 킥오프 하나
제품 페이지 열기 릴리즈와 설치 가이드 열기 GitHub 저장소 열기

LayoutRecall

슬립, 웨이크, 도크 재연결 뒤에 흐트러지는 모니터 레이아웃을 복구하는 macOS 메뉴바 유틸리티입니다.

상태: GitHub 오픈소스, 서명된 앱 다운로드, Homebrew 설치 경로 제공

  • 대상: 계속 흐트러지는 MacBook + dock + 2+ display 데스크
  • 복구 대상: macOS가 잘못 되돌린 저장된 모니터 레이아웃
  • 시작점: 믿는 데스크 하나를 저장하고, 안전할 때만 복구

Tokenmon

Claude Code와 Codex 사용을 패시브 조우와 로컬 Dex 진행으로 바꿔주는 macOS 메뉴 막대 앱입니다.

상태: GitHub source-available, DMG 릴리즈, Sparkle 업데이트, Homebrew 설치 경로 제공

  • 대상: 하루 중 AI 코딩 도구를 계속 켜두는 macOS 개발자
  • 전환: 평소 사용량을 탐험 진행도, 자동 결과, Dex 성장으로 바꿈
  • 신뢰선: 로컬 우선 수집 상태, 계정 없음, 게임플레이에 프롬프트 텍스트 불필요

Labs

지금은 실험으로 남겨두는 것

가능성이 있다고 해서 모두 완성된 제품인 척할 필요는 없습니다. Labs는 게임, 프로토타입, 좁은 유틸리티가 올바른 공개 형태를 얻을 때까지 움직이는 공간입니다.

게임

플레이 감각을 먼저 보는 아이디어와 실험

작은 게임과 인터랙션 실험은 너무 이른 시점에 제품 언어를 빌리지 않고도 Labs에서 빠르게 움직일 수 있습니다.

  • 초점: 메커닉, 리듬, 시각적 감각, 그리고 루프를 계속 가져갈 가치가 있는지
  • 공개 시점: 플레이 루프가 반복적인 개선을 견딘 뒤에만
블로그에서 스튜디오 노트 보기

실험

나중에 제품이 될 수도 있는 새로운 도구

어떤 빌드는 계속 좁은 도구로 남고, 어떤 것은 내부 유틸리티가 되며, 어떤 것은 적합성이 분명해진 뒤에만 공개 소프트웨어로 올라갑니다.

  • 초점: 넓은 플랫폼 약속이 아니라 구체적인 워크플로우 마찰
  • 승격 기준: 제품 페이지, 증거, 설치 경로가 준비되어야 공개 제품으로 이동
