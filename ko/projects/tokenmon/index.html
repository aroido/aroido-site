Tokenmon

코딩은 계속하세요. Tokenmon이 조용히 수집합니다.

Claude Code와 Codex 사용이 Mac 메뉴 막대에서 패시브 조우, 자동 결과, 로컬 Dex 진행으로 이어집니다.

계정이 필요 없고, 로컬 우선이며, 게임플레이에 프롬프트 텍스트가 필요하지 않습니다.

DMG 다운로드 Homebrew로 설치 GitHub 보기
계정 없음 로컬 우선 Dex 게임플레이에 프롬프트 텍스트 불필요

설치 경로와 수집 루프를 보여주는 스크린샷 기반 공개 미리보기입니다.

계속 켜두는 이유

방해하지 않는 playful companion

Tokenmon은 이미 일어나는 작업을 작은 배경 보상 루프로 바꿀 때 가장 잘 맞습니다.

패시브

수동 전투 플로우 없음

앱은 코딩을 멈추고 조우를 직접 탭하라고 요구하지 않습니다. 결과는 자동으로 처리됩니다.

앰비언트

메뉴 막대에서 한눈에 보입니다

현재 상태, 진행도, 최근 조우, Dex를 보고 싶을 때만 열면 됩니다. 일을 대시보드 세션으로 바꾸지 않습니다.

로컬

수집 상태는 Mac 안에 남습니다

현재 공개 빌드는 계정이나 클라우드 sync를 요구하지 않습니다. 제품 이야기는 로컬 상태와 낮은 설치 마찰에서 시작합니다.

핵심 루프

수집 루프가 느껴지는 방식

제품은 AI 코딩 활동을 탐험으로 바꾸고, 조우 결과 처리는 앱에 맡깁니다.

STEP 01

평소처럼 Claude Code나 Codex를 사용합니다

Tokenmon은 별도 플레이 세션이 아니라 기존 코딩 흐름을 기준으로 설계되어 있습니다.

STEP 02

탐험 진행도가 쌓입니다

평소 사용량이 다음 조우를 향한 진행도로 바뀌며, 게임플레이에 프롬프트나 응답 텍스트가 필요하지 않습니다.

STEP 03

생물이 나타나고 결과가 처리됩니다

각 조우는 captured 또는 escaped로 자동 종료되어 상호작용 부담을 낮게 유지합니다.

STEP 04

Dex가 로컬로 채워집니다

Seen과 Captured 진행도가 Mac 안에 누적되어 시간이 지날수록 수집이 자랍니다.

신뢰 경계

Playful하다고 해서 침습적일 필요는 없습니다

현재 공개 이야기는 의도적으로 좁습니다. 로컬 우선 수집, 계정 불필요, 게임플레이에 프롬프트 텍스트 불필요입니다.

프롬프트

게임플레이에 프롬프트 텍스트 저장이 필요하지 않습니다

Tokenmon은 사용자가 입력한 내용을 읽거나 평가하는 도구가 아니라 ambient companion으로 봐야 합니다.

계정

현재 계정이 필요 없습니다

앱을 써보는 시작점은 호스팅 대시보드나 회원가입이 아니라 Mac 설치 경로입니다.

소스

Source-available 공개 미러

공개 저장소는 배포된 스냅샷, 릴리즈 자산, 설치 채널을 담고, 일상 maintainer 워크플로우는 분리되어 있습니다.

시각 proof

실제 제품 표면은 작고, 보이고, inspect 가능합니다

메뉴 막대 루프부터 보고, 수집과 설정을 보이게 해주는 Dex와 설정 화면을 확인하세요.

  • 애니메이션 메뉴 막대 strip
  • Seen과 Captured Dex
  • 설정과 provider setup

설치

공개 Tokenmon 빌드 설치하기

GitHub Releases와 Homebrew가 현재 공개 경로입니다. Tokenmon은 macOS Sequoia 이상이 필요합니다.

옵션 A. DMG 다운로드

최신 GitHub 릴리즈에서 DMG, 릴리즈 노트, checksum, Sparkle 업데이트 메타데이터를 확인하세요.

https://github.com/aroido/tokenmon/releases/latest
GitHub Releases에서 DMG 다운로드 GitHub 보기

공개 저장소는 source-available이며 배포된 스냅샷의 릴리즈 미러 역할을 합니다.

옵션 B. Homebrew로 설치

터미널에서 설치와 업그레이드를 관리하고 싶다면 cask 경로를 사용하세요.

설치 명령

brew install --cask aroido/tokenmon/tokenmon

릴리즈 빌드는 앱 안에서 업데이트할 수 있으므로 Homebrew 경로는 주로 첫 설치와 터미널 기반 업그레이드에 적합합니다.

평소 AI 코딩 세션 하나 동안 켜두는 것부터 시작하세요.

Tokenmon은 루프가 작업 옆에 둘 만큼 조용하게 느껴질 때 의미가 있습니다. 한 세션 써본 뒤 수집을 계속할지 판단하세요.
