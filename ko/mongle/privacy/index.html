몽글그림일기

개인정보처리방침

사진과 일기는 사용자의 iPhone 안에 남습니다. 사용자가 익명 사용 정보 공유를 선택한 경우에만 몽글이 제한된 제품 이용 이벤트를 TelemetryDeck으로 보냅니다.

시행일: 2026년 7월 28일

요약

기기 안에서 처리하는 설계

몽글에는 계정, Aroido 백엔드, 광고, 추적 또는 제3자 분석 SDK가 없습니다. 일기 내용은 기기에서 처리하며, 선택적인 익명 제품 이벤트는 사용자가 동의한 뒤에만 TelemetryDeck으로 직접 전송합니다.

iPhone에서 처리

사진과 일기 콘텐츠

사용자가 허용하면 몽글은 선택한 사진 자산, 촬영일, 스크린샷 여부 및 사진에 포함된 선택적 위치 정보를 읽습니다. 일기 본문, 날씨, 테마, 작성 주기와 시간 및 선택한 사진 참조도 처리합니다.

분석으로 보내지 않음

일기 내용과 신원 정보는 제외합니다

몽글은 일기 본문, 사진, 썸네일, 위치, 파일명, 정확한 작성·알림 시각, 자유 입력문, 오류 원문 또는 사용자·기기·설치 식별자를 보내지 않습니다. 앱은 Aroido 백엔드를 사용하지 않습니다.

선택형 익명 분석

제품 이벤트 공유 여부는 사용자가 결정합니다

Aroido는 일기 흐름의 완료·이탈 지점과 유용한 테마·행동을 파악해 제품을 개선하는 용도로만 집계 이벤트를 사용합니다. 광고, 앱 간 추적 또는 개인별 프로필에는 사용하지 않습니다.

명시적 선택과 철회

초기 설정에서 몽글은 ‘공유할게요’ 또는 ‘보내지 않을게요’를 선택하게 합니다. 동의 전, 거절 후, 또는 몽글 설정에서 공유를 끈 뒤에는 분석 이벤트를 만들거나 저장하거나 전송하지 않습니다. 공유를 끄면 진행 중인 요청도 취소합니다. 어떤 선택을 해도 모든 기능을 동일하게 사용할 수 있습니다.

이벤트에 포함될 수 있는 정보

고정된 허용 목록은 온보딩 완료, 앱 열기, 권한 결과, 초안·표지 단계, 테마 선택, 저장·공유 결과, 삭제, 작성 주기와 알림 변경을 다룹니다. 이벤트에는 대략적인 진입 경로, 주기, 테마, 성공 여부, 권한, 사진 수 구간과 앱 버전·빌드·배포 방식·iOS 주 버전이 포함될 수 있습니다. TelemetryDeck은 서버가 이벤트를 받은 시각도 기록합니다.

재방문 사용자를 구분하지 않음

몽글은 TelemetryDeck clientUser 값을 비워서 보냅니다. 무작위 세션 ID는 현재 앱 프로세스의 메모리에만 존재하고 앱을 다시 열면 바뀝니다. 계정 ID, IDFA, IDFV, 기기 이름, 설치 ID를 만들지 않으며 분석 대기열을 디스크에 저장하지 않습니다.

TelemetryDeck 처리와 보관

몽글은 허용된 이벤트를 TelemetryDeck v2 수집 서비스로 직접 보냅니다. Aroido의 현재 무료 플랜에서는 최근 3개월 이벤트를 대시보드에서 조회할 수 있습니다. TelemetryDeck은 더 오래된 이벤트가 콜드 스토리지로 옮겨질 수 있다고 안내하므로 해당 서비스의 보관·개인정보 조건도 적용됩니다. 이벤트에는 재방문 사용자 식별자가 없어 Aroido가 특정 개인의 과거 이벤트만 분리할 수 없습니다.

보관과 파기

일기 내용은 사용자의 기기 설정 아래에 있습니다

일기 데이터

일기 본문과 메타데이터는 Apple SwiftData로 기기에 저장됩니다. 사진은 Apple 사진 앱에 남고 몽글은 원본을 복제하지 않고 참조합니다. 기기 백업은 사용자가 설정한 iPhone 시스템 백업 정책을 따릅니다.

임시 공유 파일

공유용 JPEG는 사용자가 요청할 때만 생성됩니다. 임시 공유 파일은 공유 완료 또는 취소 뒤 삭제되며, 앱이 비정상 종료되어 남은 파일은 다음 실행 시 24시간이 지난 뒤 삭제됩니다.

삭제

몽글 안에서 일기를 삭제해도 사진 앱의 원본은 삭제되지 않습니다. 앱을 삭제하면 시스템 백업 설정의 적용을 받는 경우를 제외하고 로컬 앱 데이터가 삭제됩니다. Aroido 서버에는 삭제할 사본이 없습니다.

권한과 선택

사용자가 선택한 기능에 필요한 권한만 요청합니다

사진

몽글은 일기 사진 선택을 시작할 때 사진 읽기 권한을 요청합니다. 완성한 일기를 공유하면 임시 JPEG를 만든 뒤 iOS 공유 시트를 열며, 사진 추가 전용 권한은 요청하지 않습니다. iOS 설정에서 읽기 접근 범위를 제한하거나 권한을 철회할 수 있습니다.

알림

일기 알림은 로컬 알림입니다. 알림은 선택 사항이며, 일기 기능을 막지 않고 몽글 또는 iOS 설정에서 변경할 수 있습니다.

Apple 서비스

몽글은 사용자의 Apple 설정에 따라 Apple 사진, iCloud 사진, MapKit 및 시스템 백업을 사용할 수 있습니다. Aroido는 Apple 서비스가 처리하는 데이터를 받지 않습니다. 해당 서비스에는 Apple의 약관과 개인정보 보호정책이 적용됩니다.

공유

공유는 사용자가 시작합니다

몽글은 사용자가 명시적으로 실행할 때만 iOS 공유 시트를 엽니다. 내보낸 이미지에는 사용자가 고른 일기 페이지가 포함되지만 원본 파일명, EXIF 메타데이터, 정확한 GPS 좌표 또는 해당 기간의 전체 사진은 포함되지 않습니다. 사용자가 선택한 공유 대상의 개인정보 처리 방식이 별도로 적용됩니다.

지원 문의

사용자가 직접 보내는 정보

사용자가 이메일로 문의하면 Aroido는 답변과 문제 해결을 위해 이메일 주소와 문의 내용을 받습니다. 지원과 법적 의무에 합리적으로 필요한 기간 동안만 보관하며, 사용자는 지원 메일 삭제를 요청할 수 있습니다.
