몽글그림일기

개인정보처리방침

몽글은 사진과 일기가 사용자의 iPhone 안에 머물도록 설계되었습니다. Aroido는 몽글의 앱 데이터를 수집하지 않습니다.

시행일: 2026년 7월 28일

요약

기기 안에서 처리하는 설계

몽글에는 계정, Aroido 서버, 광고, 추적 또는 제3자 분석 SDK가 없습니다. 앱 콘텐츠는 일기 생성, 표시 및 공유를 위해 기기 안에서 처리됩니다.

iPhone에서 처리

사진과 일기 콘텐츠

사용자가 허용하면 몽글은 선택한 사진 자산, 촬영일, 스크린샷 여부 및 사진에 포함된 선택적 위치 정보를 읽습니다. 일기 본문, 날씨, 테마, 작성 주기와 시간 및 선택한 사진 참조도 처리합니다.

Aroido가 수집하지 않음

앱 데이터는 Aroido 서버로 전송되지 않습니다

Aroido는 몽글에서 사용자의 사진, 위치, 일기 본문, 기기 식별자, 이용 활동 또는 진단 정보를 받지 않습니다. 앱은 Aroido 백엔드를 사용하지 않습니다.

보관과 파기

데이터는 사용자의 기기 설정 아래에 있습니다

일기 데이터

일기 본문과 메타데이터는 Apple SwiftData로 기기에 저장됩니다. 사진은 Apple 사진 앱에 남고 몽글은 원본을 복제하지 않고 참조합니다. 기기 백업은 사용자가 설정한 iPhone 시스템 백업 정책을 따릅니다.

임시 공유 파일

공유용 JPEG는 사용자가 요청할 때만 생성됩니다. 임시 공유 파일은 공유 완료 또는 취소 뒤 삭제되며, 앱이 비정상 종료되어 남은 파일은 다음 실행 시 24시간이 지난 뒤 삭제됩니다.

삭제

몽글 안에서 일기를 삭제해도 사진 앱의 원본은 삭제되지 않습니다. 앱을 삭제하면 시스템 백업 설정의 적용을 받는 경우를 제외하고 로컬 앱 데이터가 삭제됩니다. Aroido 서버에는 삭제할 사본이 없습니다.

권한과 선택

사용자가 선택한 기능에 필요한 권한만 요청합니다

사진

몽글은 일기 사진 선택을 시작할 때 사진 읽기 권한을 요청하고, 완성 이미지를 저장할 때 추가 전용 권한을 요청합니다. iOS 설정에서 접근 범위를 제한하거나 권한을 철회할 수 있습니다.

알림

일기 알림은 로컬 알림입니다. 알림은 선택 사항이며, 일기 기능을 막지 않고 몽글 또는 iOS 설정에서 변경할 수 있습니다.

Apple 서비스

몽글은 사용자의 Apple 설정에 따라 Apple 사진, iCloud 사진, MapKit 및 시스템 백업을 사용할 수 있습니다. Aroido는 Apple 서비스가 처리하는 데이터를 받지 않습니다. 해당 서비스에는 Apple의 약관과 개인정보 보호정책이 적용됩니다.

공유

공유는 사용자가 시작합니다

몽글은 사용자가 명시적으로 실행할 때만 iOS 공유 시트를 엽니다. 내보낸 이미지에는 사용자가 고른 일기 페이지가 포함되지만 원본 파일명, EXIF 메타데이터, 정확한 GPS 좌표 또는 해당 기간의 전체 사진은 포함되지 않습니다. 사용자가 선택한 공유 대상의 개인정보 처리 방식이 별도로 적용됩니다.

지원 문의

사용자가 직접 보내는 정보

사용자가 이메일로 문의하면 Aroido는 답변과 문제 해결을 위해 이메일 주소와 문의 내용을 받습니다. 지원과 법적 의무에 합리적으로 필요한 기간 동안만 보관하며, 사용자는 지원 메일 삭제를 요청할 수 있습니다.

방침 변경

몽글의 데이터 처리 방식이 바뀌면 필요한 경우 변경된 처리가 적용되기 전에 이 페이지와 시행일을 갱신합니다.
