公开产品

现在什么是公开的

公共通道包含具有清晰的适合故事的产品、工作 安装路径 以及解释该工具用途的产品页面。

VibeSmith

使用 Cursor 和 Claude Code 的多存储库团队的 AI 编码 仓库漂移 审计层。

状态：GitHub 上开源，带有现场演示、发行说明和 安装路径

  • 适用于：运行 3 个以上活跃 AI 编码 存储库的多存储库团队
  • 表面：漂移、隐藏耦合、上下文密集设置
  • 从以下开始：一个实时存储库、一个基线、一个更干净的启动
打开产品页面 打开发布和安装指南 打开 GitHub 存储库

LayoutRecall

macOS 菜单栏实用程序，可在睡眠、唤醒或扩展坞重新连接后恢复混乱的显示器布局。

状态：在 GitHub 上开源、已签名的应用程序下载和 Homebrew 安装路径

  • 适用于：MacBook + 扩展坞 + 2+ 不断漂移的显示器桌
  • 恢复：当 macOS 恢复错误时保存的显示器布局
  • 首先：保存一张已知良好的桌子，然后仅在比赛安全时恢复
打开产品页面 打开发布和安装指南 打开 GitHub 存储库

Tokenmon

macOS 菜单栏应用程序，可将 Claude Code 和 Codex 的使用转化为被动遭遇和本地 Dex 进度。

状态：GitHub 上提供源代码，包含 DMG 版本、Sparkle 更新和 Homebrew 安装路径

  • 适用于：白天保持 AI 编码 工具打开的 macOS 开发人员
  • 转变：正常使用转化为探索进度、自动结果和 Dex 增长
  • 信任线：本地优先收集状态，无账户，游戏无需提示文字
打开产品页面 下载DMG 查看 GitHub

Labs

目前仍处于实验阶段

并非所有有前途的构建都应该假装是成品。 Labs 是游戏、原型和狭窄实用程序不断发展的地方，直到正确的公共形状显而易见。

游戏

可玩的想法和感觉第一的实验

小游戏和交互实验可以在 Labs 中快速进行，而无需过早借用产品语言。

  • 关注点：机制、节奏、视觉感受、循环是否值得保留
  • 公开计时：仅在播放循环经受住重复迭代后
在博客上关注工作室笔记

实验

以后可能成为产品的新工具

有些构建保持狭窄，成为内部实用程序，或者仅在适合性变得明显后才升级为公共软件。

  • 重点：特定的工作流程摩擦，而不是广泛的平台承诺
  • 决策门：促销前必须准备好产品页面、证明和 安装路径
