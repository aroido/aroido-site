Tokenmon

继续编码。Tokenmon 会安静收集。

Claude Code 和 Codex 的使用变成了 Mac 菜单栏中的被动遭遇、自动结果和本地 Dex 进度。

没有帐户，本地优先，也不需要游戏提示文本。

为什么人们保持开放

一个不碍事的顽皮伴侣

当 Tokenmon 将已经发生的工作变成一个小的后台奖励循环时，它是最强的。

被动的

无手动战斗流程

该应用程序不会要求您停止编码并点击遭遇。它会自动解决它们。

周围的

菜单栏一目了然

当您想要当前状态、进度、最近遇到的情况或 Dex 视图时打开它，而不需要将工作转变为仪表板会话。

当地的

集合状态存在于您的 Mac 上

当前的公共构建不需要帐户或云同步。产品故事从本地状态和低摩擦 安装路径 开始。

核心循环

收集循环感觉如何

该产品将 AI 编码 活动转化为探索，然后让应用程序处理遇到的结果。

步骤01

像往常一样使用 Claude Code 或 Codex

Tokenmon 是围绕现有编码流程而不是单独的播放会话设计的。

步骤02

探索进展不断

正常使用会成为下一次遭遇的进度，无需游戏提示或响应文本。

步骤03

一个生物出现并解决

每次遭遇都会在被捕获或逃脱时自动结束，从而保持交互的轻量级。

步骤04

您的 Dex 在本地填充

已看到和已捕获的进度会在 Mac 上累积，因此收藏会随着时间的推移而增长。

信任边界

好玩并不意味着有侵略性

当前的公开故事故意缩小：本地优先 集合，没有帐户要求，游戏过程中不需要提示文字。

提示

游戏不需要存储提示文字

Tokenmon 应被视为环境伴侣，而不是读取或排名您键入的内容的工具。

帐户

今天不需要帐户

尝试该应用程序从 Mac 安装路径 开始，而不是托管仪表板或注册流程。

来源

源可用的公共镜像

公共存储库包含已发布的快照、发布资产和安装通道，而日常维护人员工作流程保持独立。

目视证明

安装

安装公共 Tokenmon 版本

GitHub Releases 和 Homebrew 是当前的公共路径。 Tokenmon 需要 macOS Sequoia 或更高版本。

选项 A. 下载 DMG

打开 DMG、发行说明、校验和和 Sparkle 更新元数据的最新 GitHub 版本。

https://github.com/aroido/tokenmon/releases/latest
从 GitHub Releases 下载 DMG 查看 GitHub

公共存储库具有源可用，并充当已发布快照的发布镜像。

选项 B. 使用 Homebrew 安装

如果您更喜欢从终端安装和升级，请使用 cask 路径。

安装命令

brew install --cask aroido/tokenmon/tokenmon

发布版本可以在应用程序内更新，因此 Homebrew 路径主要用于初始安装和终端驱动的升级。
