LayoutRecall

恢复 macOS 反复打乱的显示器布局。

LayoutRecall 是适用于 MacBook + 扩展坞 + 多显示器办公桌的开源 macOS 菜单栏应用程序。保存一次已知良好的布局，然后在睡眠、唤醒或重新连接后将其恢复。

自动恢复保持保守。置信度较低的案例仍故意采用手动方式。

打开发布并安装 查看视觉证据 打开 GitHub 存储库
macOS 菜单栏应用 GitHub 发布 + Homebrew 信心感知恢复

知名办公桌

保存一张您信任的办公桌，然后将其安全带回来

LayoutRecall 专为解决 macOS 以错误的顺序或位置返回熟悉的多显示器桌面后找回它的狭隘问题而设计。

  • 从当前桌面保存已知良好的布局配置文件
  • 仅当实时显示匹配度强时自动恢复
  • 当应用拒绝猜测时，保持手动恢复控件可见

开源版本的当前公共产品屏幕。

当 MACOS 出错时

LayoutRecall 旨在修复什么

该应用程序有意缩小范围：恢复您已经信任的桌面，而不是假装是完整的显示管理套件。

睡眠/唤醒

相同的监视器以错误的顺序返回

当连接的显示器组与您之前保存的配置文件高度匹配时，恢复保存的配置文件。

重新连接

Dock 重新连接更改主显示或原点

每次重新连接后，恢复已知的布置，而不是手动重建桌子。

信心不足

自动恢复会有风险

该应用程序会短暂停止，显示诊断信息，并在匹配不够强时保持恢复手动。

现在

您需要直接恢复控制

当您需要控制时，请使用菜单栏中的“立即恢复”、“应用布局”、“显示数字”和相关控件。

合身

该产品适合谁

LayoutRecall 对于那些已经知道他们想要恢复的确切显示器布局的人来说是最强的。

办公桌设置

MacBook + 扩展坞 + 2 个以上外接显示器

它专为重复办公桌而设计，其排列稳定，但 macOS 总是将显示器放回错误的位置。

相信

想要康复而不盲目猜测的人

自动恢复仅在有信心的匹配上运行。当信心减弱时，应用程序会保持透明，并将最后的行动留给您。

边界

不是一个巨大的显示管理套件

如果您想为每个四屏以上的边缘情况提供一个神奇的答案，那么该产品故意比这个承诺更窄。

目视证明

真实的 UI 证明，而不是模糊的实用声明

当前的公共版本直接在产品中显示诊断、配置文件和恢复控制，而不是将它们隐藏在猜测后面。

  • 信心感知恢复
  • 诊断保持可见
  • Pro 文件和手动回退

安装

尝试签名的应用程序或使用 Homebrew 安装

GitHub Releases 和 Homebrew 桶是最快的公共​​路径。该产品对于实际恢复命令对 displayplacer 的依赖保持诚实。

选项 A.GitHub Releases

下载签名的 DMG，将 LayoutRecall 拖到应用程序中，然后从菜单栏保存基线布局。

https://github.com/aroido/layoutrecall/releases
打开最新的 GitHub 版本 打开 GitHub 存储库

如果缺少 displayplacer，LayoutRecall 可以显示该依赖关系状态并在恢复命令运行之前指导安装流程。

选项 B.Homebrew

如果您更喜欢 Homebrew 路径，请从公共桶安装。

安装命令

brew install --cask aroido/layoutrecall/layoutrecall

恢复保存的布局仍然取决于 PATH 上可用的 displayplacer。
