# 실제 뉴욕 지도와 짧은 스크롤
Issue: https://github.com/aroido/aroido-site/issues/44
Base: 688ab452aa12e25d4edfad70fca66b7f88f8b17e (가상 버전은 사용자 새 피드백 도착 전에 이미 배포됐음을 즉시 보고)

## 요구
가상 도시를 실제 뉴욕 거리/건물로 대체한다. 연출 메모와 실제 지리 데이터를 구분한다. 확대를 긴 영화처럼 붙잡지 않고 한두 번 스크롤 안에 건물 도착/실제 앱 설명으로 연결한다. 유료 구매·키 생성 없음.

## 선택 및 출처
OSM Overpass 읽기 전용 추출본을 자체 호스팅한다. Flatiron Building (way264768896) 주변 실제 윤곽/도로으로 구성하며 ODbL1.0 출처 표시 및 추출 데이터 다운로드를 제공한다. 존재하지 않는 주소/건물/옥상 설비/주차칸을 합성하지 않는다. 높이 태그가 있는 건물만 해당 높이로 표현하며, 없는 경우 평면 윤곽으로 남긴다. 도로의 두께·색상은 지도 스타일이며 실제 차로폭 주장 아님.

## 구현/검증
Synthetic town 코드를 제거하고 실제 polygon/line geometry를 렌더링한다. 뉴욕으로 지구본 중심을 바꾼다. 320px 스크롤 안에 확대를 마치고 실제 앱 설명이 바로 나온다. 마커28px상한·4언어·출처읽기·메모연출고지·모바일프레이밍·실제데이터좌표/선택건물 확인·단위/전체검증·영상·최종운영버전 확인.

## 추가 피드백
줌아웃 상태에 작은 시연 표식을 다수 표시한다. 지구본180개·뉴욕 최대70개 후보에 픽셀8px상한, 화면밖/뒷면/중복 숨김과 단계별표시를 적용한다. 실제사용자수 주장은 하지않는다. 선택마커28px상한 유지.
