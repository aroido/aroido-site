# 네이버 서치어드바이저 HTML 소유권 인증

- Issue: https://github.com/aroido/aroido-site/issues/59
- 날짜: 2026-10-16
- 승인: 사용자가 bigcat1021 계정에 https://aroido.com/ 사이트 신규 등록, 인증 정보 배포와 소유권 확인을 명시 승인했다.

서치어드바이저의 해당 계정/사이트 UI에서 다운로드한 naver91abf19c5dae25c4057162e363b4f059.html 원문을 사이트 루트에 배치한다. 기존 Google 인증과 사이트 콘텐츠, DNS는 변경하지 않는다.

수용 기준: 다운로드 원본과 바이트 일치, full verify 통과, 독립 검토 통과, PR/main 배포 뒤 공개 URL HTTP 200 및 동일 본문 확인, 네이버 소유권 확인 성공. 사이트맵 제출은 기존 목록 확인 후 한 번 실행하고, 접수 결과와 실제 색인 완료를 구분한다. CAPTCHA는 우회하지 않는다.
