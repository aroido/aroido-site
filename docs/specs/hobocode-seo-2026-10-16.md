# Hobocode 검색 발견 경로 정비

- Issue: https://github.com/aroido/aroido-site/issues/55
- 날짜: 2026-10-16

## 범위

4개 언어의 독립 Hobocode 랜딩을 검색엔진 사이트맵에 포함한다. 일반 번역 페이지 생성 목록과 독립 랜딩 사이트맵 목록을 분리하여 생성기가 디자인과 동작을 덮어쓰지 않도록 한다. 홈페이지와 프로젝트 목록에 각 언어 랜딩 직접 링크를 추가하고 footer의 지원/개인정보 링크도 해당 언어로 연결한다. 장소 메모 앱이라는 검색 의도를 title/description/인접 소개에 반영하되 기존 H1과 온보딩 디자인은 유지한다. 기능, 출시, 가격, 평점에 대한 근거 없는 약속은 추가하지 않는다.

## 수용 기준

- 사이트맵에 4개 언어 랜딩 URL이 각각 1회 포함되며 noindex 공유 리디렉터 /hobocode/get/은 제외된다.
- 일반 번역 및 블로그 생성기를 실행해도 4개 커스텀 랜딩 HTML이 바뀌지 않는다.
- 각 언어 루트/프로젝트 페이지에서 해당 언어 홍보 랜딩으로 직접 이동한다.
- 랜딩의 canonical/hreflang과 단일 H1, 언어별 footer 링크가 유효하다.
- scripts/run-ai-verify --mode full 및 독립 변경 검토를 통과한다.
- PR/main 자동 배포 후 실제 production HTML과 sitemap을 대조한다.
- 검색엔진 제출은 검증된 기존 소유권 범위에서만 실행하며 접수와 실제 색인은 구분한다.
