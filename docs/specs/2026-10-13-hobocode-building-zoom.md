# 건물 수준 줌 및 화면 기준 마커
Issue: https://github.com/aroido/aroido-site/issues/42

## 요구
운영 모바일에서 저해상도 지구본만 확대되며 표식이 과도하게 커진다. 지구→도시→거리→개별 건물까지 연속 확대하고 최종 작은 표식과 메모를 보여준다. 실제 앱 이미지와 교정 문구 보존. 영상 우선 전달 후 검증/배포.

## 구현
자체 제작한 가상 도시의 도로·필지·건물·주차장을 실제 3D 지오메트리로 구성한다. 실제 도시나 주소로 주장하지 않고 4언어로 가상 시연임을 고지한다. 기존 Natural Earth 지구본은 원경에서만 사용하며 별도 도시 지오메트리로 상세 수준을 확보한다. 동일 카메라/중심 앵커를 유지한 연속 확대, 픽셀 기준 마커 최대 28px, 최종 메모 공개. 엔딩은 역방향.

## 검증
모바일 운영 동작 재현. 새 전체 줌 영상 우선 제공. 320/390/768/1440, camera p0..1 및 복귀/resize, 마커 크기/카드/선/장면별 식별, reduced-motion/noJS/noWebGL, 실제 앱이미지 불변, full ai-verify. PR Preview 및 운영 최종 파일 검증.

## 검증 기록
- 운영 390px에서 거대 마커/저해상도 지도 확대 재현. 새 전체 확대 모바일 영상을 검증·배포 전에 Library libfile_3f125c4add2c8191b98603341362aa9c로 먼저 전달.
- 실제 WebKit 320×568, 390×664, 768×1024 및 Chromium 1440×1000: 56개 확대/역확대/스크롤 복귀 경우 통과. 마커 투영 bounds 상한 28/22px, 연결선 끝점 오차 <0.5px, 카드 가로 넘침 없음. viewport 변경 후 크기 재계산.
- axe 위반 0, JS 오류 0, 가로 넘침 0. Reduced-motion/no-JS/forced-no-WebGL 표시 정상. 4언어×4폭 16경우 정상.
- geometry 단위 4/4, 전체 저장소 ai-verify 9/9.
- 독립 시각 리뷰: 측벽·지붕·옥상설비·주차칸으로 건물 인식 가능, 표식 중앙 유지, 320/390px 카드/연결선 차단 사항 없음.
- 기존 실제 앱 이미지 파일 변경 없음. 기존 카피 변경 없음(4언어 가상 장면 단계 고지만 추가).
- 실물 iPhone Safari 및 현장 Core Web Vitals 미측정. 도시 상세는 실제 지역이 아닌 자체 제작 가상 3D 장면.
