# 호보코드 정책 실질 변경 초안 — 게시 전 검토

상태: **미게시 초안**. Issue #22. 새 명칭·URL 변경과 별도로 검토한다. 다음 문구는 앱 main `744a2193`와 운영 배포 기록을 대조한 기술적 설명이며, 법적 보관기간·국외 이전 관계를 새로 확정하지 않는다. 현재 생성된 새 HTML과 번역에 아래 사실 교정을 반영했다. 게시 전 검토용이며 아직 공개되지 않았다.

## 1. 지도와 장소 검색

NAVER 지도 SDK와 장소 검색, Apple 검색·역지오코딩 경로를 사용합니다. 사용자가 입력한 검색어는 Cloudflare Workers 중계를 거쳐 NAVER 검색 서비스로 전달됩니다. 이 검색 요청의 본문에는 검색어만 포함하며 메모 본문과 현재 기기 좌표는 넣지 않습니다. 검색 중계의 오류·시간 초과·한도 또는 설정 상태에 따라 Apple 검색을 사용할 수 있습니다. 선택한 검색 결과나 역지오코딩에서 얻은 장소 이름·주소·좌표와 출처 정보는 장소 기록에 저장될 수 있으며, 선택적 iCloud 동기화 대상에 포함됩니다. Apple 장소 ID와 직접 입력한 별칭을 사용하는 참조 경로도 있습니다.

근거: `App/Services/NaverPlaceSearchProvider.swift:80–91`, `PlaceSearchProvider.swift:86,120–131`, `Hobocode.xcodeproj/project.pbxproj:56`. 기존 문구의 NAVER 미연결/MapKit만 사용 설명과 다름.

## 2. 선택적 iCloud 기록·사진 동기화

전송 범위를 확인하고 동의한 뒤 iCloud 동기화를 시작합니다. 현재 iCloud 기록 공간의 메모, 장소 정보·좌표, 첨부 사진, 휴지통 기록, 삭제 이력과 동기화 메타데이터를 Apple CloudKit의 사용자 비공개 데이터베이스와 동기화합니다. 초안·입력 복구 자료, 기기 전용 기록과 다른 계정 기록은 전송 대상에서 제외됩니다. 동의는 이 앱 설치와 확인된 iCloud 계정에 연결해 저장·복원합니다. 동기화를 끄거나 계정을 바꾸면 전송을 멈추지만 이미 전송한 자료를 삭제하지는 않습니다. iCloud 용량과 연결 상태에 따라 지연되거나 실패할 수 있으며, 기기 저장이나 연결됨 표시는 모든 자료의 전송 완료를 뜻하지 않습니다. 설치별 알림 누적 수 역시 같은 계정의 비공개 데이터베이스에서 동기화될 수 있습니다.

사진은 현재 기록 공간의 저장된 메모와 휴지통에 첨부한 기존 사진도 대상입니다. CloudKit 첨부 자료로 전송하며 iCloud 용량과 네트워크 데이터를 사용합니다. 초안과 다른 기록 공간의 사진은 제외합니다. 전송이 끝났다고 가정해 원본을 삭제하지 말고 앱의 동기화 상태를 확인해 주세요.

근거: `NotebookSyncRuntime.swift:180–211,247,271–295`; `CloudKitNotebookSync.swift:217,504–521,572–580`; `CloudKitReminderTally.swift:15–25,44–46`. 사진 동기화 불가·매 실행/사진 별도 동의라는 과거 설명을 대체하는 초안. 실계정 동기화 성공을 보장하지 않음.

## 3. Siri·잠금화면·자동 아일랜드

Siri·앱 단축어는 요청한 메모 본문을 앱에 전달합니다. 앱이 전면으로 열리고 기기 잠금 해제가 필요하며, 앱이 별도 음성 녹음을 저장하지는 않습니다. Siri 처리는 Apple 설정과 정책을 따릅니다. 잠금화면과 Dynamic Island에 내용을 표시하도록 선택하면 주변 사람이 메모 일부나 장소 정보를 볼 수 있습니다. 자동 아일랜드 기능을 사용하는 경우 설치·인증 식별정보, APNs 토큰, 세션·장소·메모의 식별자와 표시 갱신·만료 정보를 호보코드 중계 서버가 처리합니다. APNs에는 전달 대상 토큰과 표시용 세션·장소·메모 식별자 및 갱신·만료 정보를 보내며, 인증 식별정보 전체를 보내는 것은 아닙니다. 현재 자동 표시 요청에는 메모 본문·사진·정확한 좌표를 넣지 않으며, 표시 내용은 기기에 저장된 자료를 이용합니다. 연결·권한·운영체제 상태에 따라 표시되지 않을 수 있습니다. 표시를 종료해도 원래 메모는 삭제되지 않습니다.

근거: `ArrivalRelayClient.swift:227–230,672–673,740,833–841`; `server/arrival-relay/apns.mjs:35–39`; 인증·세션·암호화 토큰 D1 스키마. 기존 자동 relay 미운영 설명과 다름. 실제 APNs 수신 성공과 무관한 처리 구조 고지이며 성공 보장 금지.

## 4. 광고와 웹사이트 처리의 구분

앱은 Apple의 iCloud·Siri·APNs 및 지도·검색 서비스, NAVER 지도·검색과 Cloudflare 중계를 사용합니다. 현재 확인한 앱 코드에는 광고·추적·외부 분석 SDK가 연결되어 있지 않습니다. AdMob은 검토 단계이며 현재 광고 데이터 수집으로 기재하지 않습니다. 앱과 별개로 이 웹사이트는 Vercel에서 제공하고 Google Fonts에서 글꼴을 불러옵니다. HTTPS 웹페이지에는 Vercel Analytics를 불러오는 코드가 있으며 페이지 방문과 일부 웹 상호작용을 분석에 사용할 수 있습니다. 웹 요청 과정에서 IP 주소와 브라우저 정보가 서비스 제공자에게 전달될 수 있습니다.

근거: 앱 SDK/프로젝트 검색에서 AdMob/GoogleMobileAds/Firebase/외부 analytics 연결 미발견. 웹 `script.js:209–262,1257–1279`는 Vercel Analytics loader와 이벤트 경로를 포함. 공통 script.js만 보면 gtag 조건 분기이나 홈페이지 index.html:66–74에 Google Analytics loader/config가 직접 존재한다. 따라서 홈페이지 등 일부 웹페이지의 Google Analytics 구성도 새 고지에 포함했다. 개인정보/지원 페이지의 직접 삽입 및 실제 요청 여부는 별도 Chrome 확인 대상이다. 웹 분석 실제 수신/보관/쿠키 유무 미확인.
